# IBM-Data-Analyst-Capstone-Project

Capstone project for the IBM Data Analyst Professional Certificate on Coursera.
It covers data collection, wrangling, analysis and visualization, and finishes
with a dashboard on technology trends from the Stack Overflow Developer Survey.

## Contents

| Folder | Description |
|--------|-------------|
| `labs/` | Jupyter notebooks for the course labs (data collection, wrangling, EDA) |
| `data/` | Datasets used in the analysis |
| `dashboard/` | Cognos dashboard export (PDF) and screenshots |
| `presentation/` | Final PowerPoint presentation |

## Dashboard

An IBM Cognos Analytics dashboard with three tabs:

1. **Current Technology Usage:** top 10 languages, databases, platforms and web frameworks respondents have worked with
2. **Future Technology Trend:** the same categories for what respondents want to work with next
3. **Demographics:** respondents by age, country and education level
